Exercise 01: Core Fundamentals

Variables, Scoping, Primitive Types, Functions, and Iteration in JavaScript

How to Complete This Exercise

  1. Open 01-core-fundamentals/fundamentals.js in your editor.
  2. Follow the numbered // TODO: Step X comments to write your code.
  3. Uncomment the Verification Log Output block at the bottom of fundamentals.js.
  4. Open the DevTools Console (F12 or Cmd+Option+I) in this browser window to see your output!
  5. Alternatively, run node 01-core-fundamentals/fundamentals.js directly in your terminal.
💡 DevTools Tip: Check the "Console" tab of DevTools to see outputs produced by console.log().
