# FullStackJS-103: Solution Sets

This directory contains the complete reference solutions for all exercises in **FullStackJS-103: Vanilla JavaScript in the Browser**.

---

## 📂 Directory Layout

```text
solutions/
├── 01-core-fundamentals/
│   ├── fundamentals.js       # Solved: const/let, primitives, functions, loops & array methods
│   ├── index.html            # Browser testbed
│   └── styles.css
├── 02-dom-manipulation/
│   ├── dom-manipulation.js   # Solved: querySelector, node traversal, content/class/attribute updates, element creation
│   ├── index.html            # Metrics dashboard UI
│   └── styles.css
├── 03-event-handling/
│   ├── events.js             # Solved: form submission, preventDefault, delegation, dynamic DOM, live search filter
│   ├── index.html            # Interactive task sprint board
│   └── styles.css
└── package.json              # Solution dependency and test runner manifest
```

---

## 🚀 Running and Testing Solutions

### 1. Verify Module 01 in the Terminal
```bash
node solutions/01-core-fundamentals/fundamentals.js
```

### 2. Preview All Solutions in the Browser
From the workspace root, run:
```bash
npx serve .
```
Navigate to:
- `http://localhost:3000/solutions/01-core-fundamentals/`
- `http://localhost:3000/solutions/02-dom-manipulation/`
- `http://localhost:3000/solutions/03-event-handling/`
